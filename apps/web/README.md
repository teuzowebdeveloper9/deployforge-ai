# Web

Next.js App Router frontend for DeployForge AI.

## Screens

- `/apps`
- `/apps/new`
- `/apps/[appId]`
- `/apps/[appId]/versions`
- `/apps/[appId]/builds`
- `/apps/[appId]/agent`

No `/skills` route exists in this phase.

## Commands

```bash
npm install
npm run lint
npm run typecheck
npm run build
```
